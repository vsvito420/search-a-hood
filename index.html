🎯 Meine Ziele · Pendeln

Echte Reisezeit von jeder Lage zum Ziel (Rad/Fuß/Auto: FOSSGIS-OSRM, ÖPNV: Transitous, Ankunft nächster Werktag). Ziele erscheinen als Module unter „Meine Ziele“.

Module

➕ Eigenes Modul

Syntax wie Overpass QL: [key] [key=value] [key!=v] [key~"regex"], mehrere mit ; trennen (ODER). Tags: OSM Map Features.

Wohnungs-Kandidaten

Adressen aus Inseraten einfügen – eine pro Zeile. Optional mit | getrennt: Adresse | Kaltmiete € | m² | Link. Oder Shift+Klick auf die Karte.

Overlays (WMS / Kacheln)

Behördliche Geodaten über die Karte legen. Aktive WMS-Layer werden beim Klick auf die Karte am Punkt abgefragt (GetFeatureInfo).

➕ Eigener WMS / XYZ

Lärmkarten, Hochwasser, Bodenrichtwerte usw. gibt es als WMS von den Geoportalen der Länder.

Teilen & Konfiguration

Deep-Links

Die App lässt sich per URL steuern, z. B. aus einer Tabelle mit Inseraten:

?addr=Oranienstraße 185, Berlin&preset=informatiker&run=1
?at=52.4986,13.418&z=16&walk=1&time=2026-10-02T23:00&run=1

addr oder at, z Zoom, preset, walk=1, time, run=1 analysiert sofort und öffnet den Report.

Export

Overpass-Instanz

Eigene Instanz (z. B. http://localhost:12345/api/interpreter) für große Gebiete ohne Fair-Use-Limit.

Antworten werden 24 h im Browser gecacht (IndexedDB).

So geht's

  1. Auf dein Wunsch-Viertel zoomen (oder / Adresse suchen)
  2. Links ein Preset wählen – z. B. 🧑‍💻 Informatiker – oder Module einstellen
  3. 🔍 analysieren (A): grün = passt, grau = Pflicht verletzt
  4. Die Karte bewegst du frei. Den Report öffnest du mit Rechtsklick oder langem Tippen, oder mit dem 🎯-Prüfmodus (P)

Wohnungen vergleichen: Tab „Wohnungen“. Arbeit/Uni: „Meine Ziele“. Alles andere: Ctrl+K.
